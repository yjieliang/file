# 人物·克莱恩·莫雷蒂（愚者）

> **适用作品**：第一部《诡秘之主》主角。第二部《宿命之环》中作为旧日级存在出场。

## 一、人物概要

- 真名：周明瑞（穿越前）/ 克莱恩·莫雷蒂（穿越后）
- 国籍：鲁恩王国（阿霍瓦郡廷根市）
- 毕业院校：霍伊大学历史系
- 核心途径：**占卜家（愚者）**；对应源质：源堡；位阶：**旧日·诡秘之主**
- 化名：夏洛克·莫里亚蒂、格尔曼·斯帕罗、道恩·唐泰斯、梅林·赫尔墨斯等
- 所属组织：**塔罗会**（召集者，以"愚者"身份）

### 尊名

**愚者**：不属于这个时代的愚者 / 灰雾之上的神秘主宰 / 执掌好运的黄黑之王

**格尔曼·斯帕罗**：灵界和源堡的眷者 / 源自古代的诡秘 / 漫长历史的见证 / 贝克兰德所有贫困孩子的保护者 / 伟大的格尔曼·斯帕罗

**"海神"卡维图瓦**：大海与灵界的眷者 / 罗思德群岛的保护者 / 海底生物的支配者 / 海啸与暴风的掌控者 / 伟大的卡维图瓦

## 二、外貌

- **克莱恩·莫雷蒂**：黑发褐瞳，五官普通，轮廓较深；中等身材，体型单薄，有明显书卷气。
- **周明瑞**：眸子深棕，黑发较短，五官没什么特色，长得还算斯文，但眼袋明显。
- **夏洛克·莫里亚蒂**：黑发褐瞳，嘴边留有胡须，戴着金边眼镜，书卷味被胡须遮住。
- **格尔曼·斯帕罗**：黑发整齐斜梳，深棕色眼眸，脸庞消瘦，棱角分明，金边眼镜，气质冷峻锐利。
- **道恩·唐泰斯**：近四十岁，黑发夹杂银丝，蓝眼幽邃，身高180出头，成熟儒雅。
- **梅林·赫尔墨斯**：五官普通，让人无法产生深刻记忆。

## 三、家庭

- 父亲：皇家陆军上士，牺牲于南大陆殖民冲突
- 母亲：黑夜女神信徒，在克莱恩通过霍伊大学入学考试那一年过世
- 哥哥：**班森·莫雷蒂**，贝克兰德政府公务员，已婚有一女
- 妹妹：**梅丽莎·莫雷蒂**，贝克兰德技术大学学生

### 夏洛克·莫里亚蒂
来自间海郡的私家侦探，居住在贝克兰德乔伍德区明斯克街15号。为消化"无面人"魔药前的伪装身份，对外宣称信仰蒸汽与机械之神（为避开值夜者），是机械之心的线人。

### 格尔曼·斯帕罗
外貌冷峻锐利，以冷酷与疯狂闻名的海上冒险家。主要用于消化"无面人"魔药及作为"世界"身份与塔罗会成员接触。对外宣称信仰愚者，以愚者的狂信徒闻名。

### 道恩·唐泰斯
近四十岁、刚移居贝克兰德的神秘富翁。伪装三层身份：表面为变卖地产准备投资的乡绅；中层为在南大陆冒险积累财富的冒险者；底层为掌握反占卜技巧的诈骗犯。用于深入上流社会调查大雾霾真相。

### 梅林·赫尔墨斯
自称"奇迹魔术师"的流浪魔术师，为扮演"奇迹师"而创造。发明了"全自动许愿机"。

### "愚者"
复苏中的古神，借助塔罗会隐秘地完成一些事情，逐步取回权柄。实际是克莱恩初次塔罗会时情急之下做的伪装，是塔罗会的召集者与见证者。

### "世界"
愚者的眷者群体在塔罗会中的代表，以格尔曼·斯帕罗这一身份为塔罗会众人所知，实际是克莱恩利用秘偶大师能力捏的假人。
