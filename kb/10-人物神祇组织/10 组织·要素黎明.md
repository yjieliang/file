# 组织概要

| 属性 | 内容 |
| --- | --- |
| 全称 | 要素黎明（The Dawn of Elements） |
| 类型 | 新生隐秘组织 |
| 创立年代 | 约百余年前至两百年前（第五纪），为近一两百年内诞生的新生组织之一 |
| 创始人 | 贝尔纳黛·古斯塔夫（Bernadette Gustave） |
| 首领 | 贝尔纳黛·古斯塔夫（称号"神秘女王"、"黎明号"的主人） |
| 主要基地 | 迷雾海拉夏岛——**翡翠城**（Emerald City） |
| 旗舰 | **黎明号** |
| 敌对组织 | **摩斯苦修会**（Moss Ascetic Society） |
| 所属途径 | "窥秘人"途径（为首领所属途径） |
| 核心格言 | "为所欲为，但勿伤害"（"窥秘人"途径格言） |

**简介**：要素黎明是第五纪诞生于大海之上的新生隐秘组织，与"极光会"、"铁血十字会"、"心理炼金会"并列。该组织由罗塞尔大帝的长女贝尔纳黛·古斯塔夫创立，旨在对抗信仰"隐匿贤者"的古老组织——摩斯苦修会。组织糅合神秘学各个流派的要素，发展出自身独特理论，其成员擅长施法，掌握诸多古老巫术。首领贝尔纳黛同时也是纵横五海的"四王"之一，人称"神秘女王"。该组织与贝尔纳黛率领的海盗舰队共同构成她在海洋上的势力体系。

### 创立背景

贝尔纳黛·古斯塔夫是罗塞尔大帝的长女。据罗塞尔日记记载，因贝尔纳黛出生时父母均是低序列非凡者，她得以自由选择自身道路，不必继承父亲的途径。她曾表达对"为所欲为，但勿伤害"这一窥秘人格言的欣赏。

罗塞尔大帝晚年转向"窥秘人"途径，计划成为序列1"知识皇帝"，以保护女儿免受"隐匿贤者"的侵蚀影响。日记中写道："等我成为了'知识皇帝'，贝尔纳黛就更不用担心'隐匿贤者'的灌输了，也不用害怕知识的追逐。"据查拉图的预言，贝尔纳黛"将成为神秘世界的一位大人物"。

### 创立与对抗摩斯苦修会

要素黎明由贝尔纳黛创立，主要目的是对抗**摩斯苦修会**——信仰"隐匿贤者"的古老组织，成立于第四纪初期。

摩斯苦修会曾一度坚持道德与戒律、追求知识并严格守秘，"为所欲为，但勿伤害"的窥秘人格言最早即由该组织传出。但后来"隐匿贤者"苏醒，带来了邪恶和堕落。

两者之间的对抗不仅是组织之争，也反映了"窥秘人"途径内部对知识本质理解的分裂。要素黎明因贝尔纳黛拥有多件"0"级封印物，才能与第四纪初期便已诞生的摩斯苦修会抗衡。

### 理念与风格

贝尔纳黛谨守"为所欲为，但勿伤害"的窥秘人格言，在行事上有所克制，不会做过分的事情。克莱恩曾评价，若是贝尔纳黛控制某方势力，"不会做过分的事情"。

要素黎明与"心理炼金会"类似，糅合了神秘学各个流派的要素，拥有自成体系的理论。成员普遍擅长施法，掌握诸多古老巫术与魔法。

### 关键事件

- **贝尔纳黛探索贝克兰德**：为了解父亲罗塞尔的秘密，贝尔纳黛曾化装入场参观罗塞尔纪念展，试图寻找"亵渎之牌"等线索。

- **巨人王庭海域探索**：贝尔纳黛与克莱恩（化身格尔曼·斯帕罗）在巨人王庭投影海域相遇，她透露了"真实造物主"呓语和神弃之地入口等重大秘密。

- **贝克兰德"黑皇帝"陵寝之战**：贝尔纳黛利用"许愿神灯"（编号0—05）的第二个愿望[^1]，获得了"一天的知识皇帝实力"，与序列1"秩序之手"威廉·奥古斯都一世激战，为主战场争取了关键时间。

[^1]：前两个愿望可通过语言和准备规避危害，但绝对不能许第三个愿望。该规则源自罗塞尔的告诫。

- **向序列2"贤者"晋升**：贝尔纳黛在"黑皇帝"罗塞尔陵寝中借助"贤者额饰"与"苍白的死亡"面具，完成晋升仪式，成为"窥秘人"途径序列2天使"贤者"。晋升过程中，遭遇"隐匿贤者"干扰，但被克莱恩（"愚者"）隔绝，最终成功晋升。此后"橘光"希拉里昂奉"愚者"之命告知她星空与外神的真相。

- **传承交接**：贝尔纳黛探明父亲罗塞尔的秘密藏匿地后，将嘉德丽雅召回翡翠城，移交了"许愿神灯"等重要物品，并将要素黎明托付给新的首领，随后驾驶"黎明号"深入迷雾海进行漫长的搜寻，面临"永远无法返回"的可能。

- **封印罗塞尔**：贝尔纳黛在"愚者"帮助下进入"黑皇帝"陵寝封印被污染的罗塞尔大帝，完成了与父亲的最后告别。

### 领导模式

要素黎明实行以首领为核心的集权结构，贝尔纳黛是整个组织的最高决策者与庇护者。组织未设置复杂的议事架构。

### 成员构成

组织成员在神秘学上**擅长施法**，掌握**古老巫术与魔法**，糅合各流派要素。

贝尔纳黛手下涵盖两大势力：
- **要素黎明**：隐秘非凡者组织
- **一群海盗**：受贝尔纳黛指挥的海上舰船与海盗船员

### 传承机制

贝尔纳黛若遭遇不测无法返回，**要素黎明将产生新的首领**，不会因为一个人的消失而瓦解。她在前往迷雾海前将组织事项与重要物品分别处置：将"许愿神灯"与自身安危交由嘉德丽雅，而"剩下的所有都将留给要素黎明"。

### 锚（Anchor）机制

**要素黎明成员**以及**属于贝尔纳黛的船员、水手**的日常祈祷，是贝尔纳黛晋升序列2时所倚靠的"锚"，帮助她对抗体内产生的古老意志。

### 外交关系

- 与**摩斯苦修会**：长期对抗关系
- 与**"愚者"克莱恩**：合作关系，贝尔纳黛通过嘉德丽雅与塔罗会间接联系，并多次接受"愚者"的援助（晋升贤者、封印罗塞尔等）
- 与其他"四王"：海上势力间的竞争性共存

### 贝尔纳黛·古斯塔夫（Bernadette Gustave）

**首领兼创始人**。罗塞尔大帝的长女，纵横五海的"四王"之一，人称"神秘女王"（Mysterious Queen），也是"黎明号"的主人。

| 项目 | 内容 |
| --- | --- |
| 途径 | "窥秘人"途径 |
| 序列进程 | 序列7"巫师" → 序列6"卷轴教授" → 序列5（名称未见记载） → 序列4"神秘学家" → 序列3"预言大师" → **序列2"贤者"** → 曾通过"许愿神灯"临时获得序列1"知识皇帝"实力 |
| 核心能力 | "神秘再现"（序列4核心能力，体现"知识就是力量"）；童话魔法（由罗塞尔所讲故事衍生） |
| 封印物持有 | "许愿神灯"（编号0—05）、"苍白的死亡"（面具封印物）、曾持有"贤者额饰"（晋升时粉碎）等多件"0"级封印物 |
| 尊名 | "追逐知识的圣灵；神秘世界的灯塔；窥视命运的眼睛；大海之上的王者；圣洁的贝尔纳黛·古斯塔夫" |

**外貌特征**：高挑身材，栗色长发简简单单披着，蔚蓝眼眸，眉毛又长又直。穿着风格带有地球风却又不完全脱离当代潮流，穿衣品味独特。

**性格特点**：谨守"为所欲为，但勿伤害"格言，行事克制理智。面对要素黎明遭遇的种种大事时异常冷静、果断。对父亲罗塞尔怀有深切感情，终生追查其被害真相。外表威严，内心深处保留了对父亲的眷恋与对过往的感伤。

### 拉蒂西亚·多瑞拉（Latitia Doria）

**身份存疑**的考古学家兼冒险家。据艾德雯娜介绍，传闻她是"摩斯苦修会"或"要素黎明"的成员。

她与三位同伴在西弥姆岛原始丛林深处的废弃神庙中获得了一件涉及"海神"的重要物品，间接导致了"海神"的覆灭，一度被反抗军追杀。当地反抗军首领卡拉特和埃德蒙顿也委托克莱恩寻找她。

> **【——】**：拉蒂西亚是否确为要素黎明成员，书中未明确确认。她在西弥姆岛的行动是否受贝尔纳黛指使，同样未知。如需补充，建议查证后续嘉德丽雅与该事件的关联。

### "银币毒蛇"奥德尔（Odell the "Silver Coin Viper"）

自称"为'黎明号'主人服务"的冒险家。

> ****：奥德尔自称服务于贝尔纳黛，但不确定是否为要素黎明正式成员。

### 嘉德丽雅（Katelyn / "星之上将"）

**曾经的追随者，现已脱离**。嘉德丽雅曾是"黎明号"的船员，年少时便跟随贝尔纳黛，后因加入摩斯苦修会而近乎决裂。但她与贝尔纳黛实为表面决裂，私下仍保持通信与忠诚。贝尔纳黛将最重要的"许愿神灯"和秘密事项托付于她。嘉德丽雅后来成为"星之上将"、塔罗会的"隐者"女士。

> 嘉德丽雅是"窥秘人"途径序列3"预言大师"，是贝尔纳黛之外与要素黎明关系最密切的人物，但并非要素黎明现役成员。
