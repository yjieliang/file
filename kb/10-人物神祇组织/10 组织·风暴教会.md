## 概要

- **风暴教会**，亦称**风暴之主教会**，是《诡秘之主》世界观中信奉"风暴之主"列奥德罗的正神教会，与黑夜女神教会、蒸汽与机械之神教会并列为鲁恩王国的三大主流教会之一。
- **总部**位于苏尼亚海上的**帕苏岛**，岛上建有**风暴之渊**教堂（"总部里的总部，圣殿中的圣殿"）与**雷霆教堂**。
- 贝克兰德的**圣风大教堂**曾是风暴教会总部，一千多年前已搬迁，但至今仍被信徒视为**圣地**之一。
- 教会对应**水手途径**（亦称风暴途径）：序列9水手 → 序列8暴怒之民 → 序列7航海家 → 序列6风眷者 → 序列5海洋歌者 → 序列4灾难主祭 → 序列3海王 → 序列2天灾 → 序列1雷神 → 序列0暴君。

## 历史

- **总部迁移**：贝克兰德曾经是风暴之主教会的总部，直到上个纪元末（第五纪初）鲁恩王国建立，教会才将圣坛搬迁到帕苏岛。因此，风暴之主的贝克兰德教区仅次于七大教会总部，资料丰富程度可想象。
- **圣风大教堂**：位于贝克兰德乔伍德区，曾是风暴教会总部，一千多年前总部迁往帕苏岛后仍为圣地。塔罗会成员"倒吊人"阿尔杰曾在此被"愚者"无声"降临"回应。
- **地上神国**：位于帕苏岛的"风暴之渊"是"风暴之主"的地上神国，与现实世界只隔一座虚幻"大门"。克莱恩（书中）据此推断"当神灵不再行于地上，祂们的国就成为了各自教会的总部"。
- **对异信仰的打击**：罗思德群岛土著原本信仰"海神"卡维图瓦，被彻底殖民后明面上被取缔，风暴教会持续打击异教徒，连黑夜教会和蒸汽教会都无法在此拓展，只有不多的教堂；反抗军主要支柱就是"海神"信徒。
- **枢机会议决议权**：教会大事由枢机会议决策，如"尼根公爵被刺杀了，枢机会议让所有代罚者和教士留意侠盗'黑皇帝'相关的情况"。
- 教会内部流传着对女性的歧视倾向（据值夜者队长邓恩转述，风暴信徒卢尔弥"对女性的态度让人厌恶"），此系外部视角的评价，非教会内部文献。

## 组织架构

| 层级/机构 | 说明 |
| --- | --- |
| **风暴之主**（列奥德罗） | 教会最高信仰对象，序列0"暴君"，水手途径顶端；真名"列奥德罗"，以巨人语诵念可引发闪电 |
| **枢机会议** | 教会最高决策机构，可下达针对全国的命令 |
| **枢机主教** | 最高神职阶层之一，同时兼任大教区大主教：如艾斯·斯内克（贝克兰德教区）、亚恩·考特曼（罗思德海域） |
| **大主教** | 大教区主官，如贝克兰德教区大主教艾斯·斯内克 |
| **高级执事** | 可参与枢机会议的高级神职人员，如驻守罗思德海域的科尔多瓦·罗耶 |
| **教区主教** | 次级教区主官，如拜亚姆教区主教乔戈里（驻"海浪教堂"） |
| **牧师** | 基层神职人员，如阿尔杰·威尔逊身着牧师长袍 |
| **代罚者** | 教会的非凡者审判/执法机关，对应黑夜教会"值夜者"、蒸汽教会"机械之心" |
| **执事** | 代罚者体系内的中层，如帕苏岛总部以三位"代罚者"执事询问述职者 |

### 1. 列奥德罗（"风暴之主"）
- 真神，序列0"暴君"；真名为"列奥德罗"（巨人语/风暴途径）。克莱恩用巨人语诵念其名可引动上百道闪电交缠落下。
- 第五纪前的身份：古代天使"风天使"列奥德罗，与"纯白天使"奥赛库斯、"暗天使"萨斯利尔、"黑夜女神"阿曼妮西斯、"战神"巴德海尔并列。
- 精灵"天灾女王"高希纳姆语："风暴的神座被列奥德罗占据了，而我无力反抗'暴君'。"

### 2. 阿尔杰·威尔逊
- 塔罗会"倒吊人"，"幽蓝复仇者号"船长，风暴教会牧师（着绣闪电花纹长袍/牧师长袍）。
- 初登场即与奥黛丽同被拉入灰雾之上"愚者"的聚会，成为塔罗会最初成员之一。
- 出身：深蓝头发混血儿，幼年被挑选入帕苏岛总部儿童唱诗班，因无唱歌天赋被打发回出生岛屿小教堂做仆役。
- 在教会内隐瞒晋升进度：想瞒着教会晋升序列6再重复晋升，于三年内成为序列5"海洋歌者"，以保"幽蓝复仇者号"船长之位，避免秘密曝光。
- 序列变化：序列6"风眷者"→（在塔罗会获得"海洋歌者"魔药配方与非凡特性）→晋升序列5。
- 对教会态度：虽屡次出卖教会情报、消极怠工，但自认仍是"风暴之主"信徒，"只是不太虔诚，不够狂热"。
- 后续在塔罗会与"愚者"合作日益加深，逐渐远离"风暴之渊"。（出处同前）

### 3. 艾斯·斯内克（"神之歌者"）
- 风暴教会枢机主教之一、贝克兰德教区大主教。
- 负责乔伍德区非凡事件，管辖圣风大教堂；齐林格斯刺杀事件中率"代罚者"飞行赶到尼根公爵府邸围堵。
- 尼根公爵持有其赠与的神奇物品，吹响后艾斯·斯内克能听到动静并锁定位置。

### 4. 亚恩·考特曼
- 风暴教会枢机主教、罗思德海域大主教，"群岛超凡世界的真正统治者"。
- 序列3半神（"海王"），能改变天气压制"海神"卡维图瓦的力量；"如果在海上，即使'五海之王'和'神秘女王'也赢不了他"。
- 直接向乔戈里主教下达"调查'疯船长'康纳斯·维克托相关的人和事"的任务。

### 5. 乔戈里
- 拜亚姆教区主教，驻"海浪教堂"；阿尔杰的顶头上司之一，负责向考特曼汇报。

### 6. 科尔多瓦·罗耶
- 高级执事，能参与枢机会议；罗思德海域为"风暴教会的关键教区，长期有一位能参与枢机会议的高级执事驻守此地"，他带领两支"代罚者"小队出动。

### 7. 米勒主教
- 罗思德群岛（班西港附近）的风暴主教，曾告知艾尔兰等人当地古老习俗复苏导致一位风暴主教堕落。

## 代罚者（Punishers）

- 性质：风暴之主教会的非凡者执法/审判机关，与黑夜女神教会"值夜者"、蒸汽与机械之神教会"机械之心"同类的存在。
- 分工（廷根）："隶属于风暴之主教会'代罚者'队伍的第六小组负责码头区、东区和南区"。
- 与"值夜者"等的共同境遇：各教会审判机关每年处理的事件中约有四分之一是**非凡者失控**，且失控者中很大一部分是队友——此系值夜者队长邓恩所述之共同背景，非风暴教会专属文献。
- 述职流程：帕苏岛总部对述职的神职人员（如阿尔杰）由三位"代罚者"执事进行询问。
- 代罚者精英可获准动用1级封印物执行枢机会议交办的任务（尼根公爵刺杀案调查）。

| **帕苏岛** | 风暴教会总部所在地、真神眷顾之地；岛上中部山峰顶端有"风暴之渊"教堂，另有"雷霆教堂"（述职场所） |

| **河与海教堂** | 廷根北区的风暴之主教会教堂，与黑夜教会圣赛琳娜教堂、蒸汽教会圣数教堂共同支撑廷根宗教界 |
| **海浪教堂** | 拜亚姆教区主教乔戈里驻地，阿尔杰述职补给时的汇报处 |
