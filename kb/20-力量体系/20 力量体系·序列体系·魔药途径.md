# 一、体系总规则

1. 体系名为"神之途径"，在第一块亵渎石板之后出现。通过服食魔药完成生命层次的晋升，最终成神。
2. 共 **22 条**途径。
3. 每条途径 **序列9 到序列 共 10 个序列**。**注意：不是 9 个。**
4. 途径命名有两套口径：以序列9 代指（通行做法）、以序列0 称呼（见识更广者）。引用时必须标明用的是哪一套。
5. 位阶划分：序列4 以上＝半神；序列2 以上＝天使；天使首领＝天使之王；序列0＝真神。
6. 数量约束：同一途径正常只能有一位序列0 **或**三位序列1；不同途径的序列2 数量不同（例："诡秘侍者"满额时，"奇迹师"只能有六位）。

## 三、晋升机制（全部）

| 机制 | 内容 |
| --- | --- |
| 魔药构成 | 主材料＋辅助材料。主材料分量可略少但不可偏太多，否则晋升失败；**分量绝不能多**，哪怕一点点都会造成严重后果。低序列魔药的辅助材料几乎不含灵性 |
| 直接服食非凡特性 | 可直接获得对应能力，但极易当场疯狂、失控；需配合辅助材料缓冲 |
| 扮演法 | 关键不是掌握，是**消化**。通过解读魔药名称获得核心象征与具体意象，在日常生活中贴合，总结扮演守则，从而降低失控风险、加速消化 |
| 仪式 | **从序列5 开始**需要。序列1–5 的仪式本质是避免因非凡特性骤增而失控，起稳定作用（类似锚的作用）。**仪式并非必需**，直接服下也有一定机会成功 |
| 晋升序列0 | **必须举行仪式**，让唯一性与三份序列1 非凡特性完全聚合、发生质变 |
| 晋升旧日 | **不需要仪式**。容纳顺序建议：先成为一条途径的序列0 → 掌控并融合源质 → 最后容纳另外的唯一性（最优）；成为双途径真神后融合源质（不好不坏）；最后一步才融合源质（最差） |
| 锚 | 成为天使以上后必须有足够的锚（通用的锚是凡人的信仰），用于形成认知、定位与形象，与非凡特性内的精神烙印对抗 |
| 唯一性 | 序列0 魔药配方中最重要的非凡材料，相当于序列0 层级的神奇物品，归于抽象与概念，代表神灵权柄 |

## 四、非凡特性三大定律

1. **不灭定律**：非凡特性不会毁灭、不会减少，只是从一个承载物转移到另一个承载物。
2. **守恒定律**：往往指相近途径非凡特性守恒；高序列多则低序列少。每条途径最多只能有一个序列0 或三个序列 且序列0 与序列1 不能并存。同一途径内，序列越高，彼此冲突可能越大。
3. **聚合定律**：同一途径的高序列物品会间歇性、无意识地吸引中低序列非凡者靠近，彼此有聚合倾向；高序列可察觉这种吸引。相近途径同样存在聚合定律。

## 五、神秘学四层结构

| 层 | 说明 |
| --- | --- |
| 精神体 | 非肉体部分的最核心，是最根本的灵性 |
| 星灵体 | 位于精神体之外，是精神体与灵界、星空沟通的方式，与本身意志和当前情绪直接相关。占卜和许多魔法均通过星灵体施展 |
| 心智体 | 与肉体有了结合，牵涉头脑，是推理、思考、洞察与认识事物能力的综合呈现 |
| 以太体 | 最外层，是生命能量与肉体状态的表现，其外显象征为气场 |
