# 一、途径概要

- **全称**：秘祈人途径 / 倒吊人途径（序列0名称命名）
- **全知全能五途径之一**（另四条为观众、歌颂者、阅读者、水手）。
 - 原著佐证：第三卷「太阳」途径序列4无暗者可与水手、阅读者互换→延伸至秘祈人和观众
 - 原著原文：「'风暴'、'太阳'、'观众'、'阅读者'和'秘祈人'是相近途径。」
- **对应源质**：**混沌海**。
 - 原著佐证：「古神们怀疑地底污染的源头就来自类似'源堡'的地方，称呼它为'混沌海'」；混沌海为全知全能五途径对应源质这一设定为编者推断
- **相邻途径**：**水手途径、观众途径、阅读者途径、歌颂者途径**（五者互为相邻）。
- **序列0 名称**：**倒吊人**。
- **对应塔罗牌**：**12-倒吊人**（XII THE HANGED MAN）。
- **当前真神**：**真实造物主**（又称堕落造物主）。
 - 原著原文：「极光会崇拜'真实造物主'，以倒吊的巨人作为那位存在的象征」
 - 原著原文：「极光会掌握着'秘祈人'途径，这是直接靠近'真实造物主'的道路」
 - 原著原文：「更愿意称呼祂为，堕落造物主」
- **别名**：序列8「倾听者」白银城称为「**耳语者**」。
 - 原著原文：「序列8'耳语者'，序列7'隐修士'，序列6'蔷薇教士'，序列5'牧羊人'」
- **途径评价**：最易失控最容易疯狂的非凡道路。
 - 原著原文：「'秘祈人'途径，也就是'牧羊人'途径是最容易失控最容易疯狂的非凡道路，没有之一，哪怕代表张扬恶意的'深渊'途径，也要差一点。」

### 序列9 - 秘祈人

**非凡能力**
- 灵感获得极大提升，能察觉到某些神秘恐怖的存在。
- 掌握一定的祭祀知识和少量仪式魔法。

- 已知魔药附带的知识中含有真实造物主和命运天使**乌洛琉斯**的尊名。

- 「根据值夜人内部资料记载，极光会掌握的序列9叫做'秘祈人'，这些非凡者能够察觉到某些神秘恐怖的存在，掌握了一定的祭祀知识和少量仪式魔法，有足够的证据表明，资深的'秘祈人'或多或少都会出现认知观点的扭曲，且容易失控。」

### 序列5 - 牧羊人

**非凡能力**
- "**放牧**"：核心能力。将别人的灵魂（包括怨魂和恶灵）吞噬到体内，对应使用他们一定的能力，就像在为神灵放牧羔羊。
- 有数量限制（最高7个），可以更替。一次只能驱使一个灵魂。
- 能瞬间改变被驱使的灵魂（对比：神奇物品"蠕动的饥饿"需要至少1秒切换）。
- 被驱使的灵魂只能使用1-3种能力。
- 牧羊人被认为半神之下最全面、最没有短板、堪称最强的非凡者。
- 随序列提高，放牧的灵魂能使用的非凡能力会越来越多。

**原著佐证**
- 「每一位'牧羊人'都能将别人的灵魂，包括怨魂和恶灵，吞噬到体内，并用独特的方式驱使这些灵魂，对应使用他们一定的能力，就像在为神灵放牧羔羊一样。」
- 「所以，谁也不知道'牧羊人'究竟具备多少能力，这只取决于他们吞噬了多少非凡的灵魂，而这让他们显得非常可怕，近乎等于高序列的强者。」
- 「但有人怀疑，'牧羊人'能吞噬和放牧的灵魂是有数量限制，但可以做更替。」
- 切换对比：「首先是切换状态太慢，需要至少一秒钟的时间，而真正的'牧羊人'瞬间就能改变，其次是被驱使的灵魂只能使用生前一到三种能力」
- 「这让我前所未有地体会到了'牧羊人'的强大，这不愧是半神之下最全面最没有短板堪称最强的非凡者！」
- 「随着序列的提高，'牧羊人'途径的圣者和天使，能放牧的灵魂能使用的非凡能力会越来越多」
- 『我心里闪过的第一个想法就是，能吞噬、放牧、驱使其他序列者灵魂和特性的'牧羊人'途径，而这条途径的尽头正是'真实造物主'。』
- 「原来'牧羊人'的含义是这个啊……'极光会'掌握的序列途径一如既往的诡异」

### 序列1 - 暗天使

**非凡能力**
- "**黑暗**"：权柄体现——变出漆黑的、粘稠的、满是堕落气息的"海洋"。
- "**秽语**"：更进一步，带着强烈"堕落"感的声音。
- "**阴影统治者**"：掌控并利用阴影世界（非主宰）。
- "**堕落眷属**"：放牧的每个灵魂（最多22个）均可外放为临时眷属。
- 本质：远古太阳神分离出的"暗"的那一面。

**原著佐证**
- 「后来，祂分离了自己体内的暗，用它和自身的一根肋骨创造了第一位天使，那就是'暗天使'萨斯利尔。」（第六卷 阿罗德斯回答 L97112）
- 「祂将自身一部分特性和对应的负面人格分离了出去，以自身肋骨为材料，造出了'暗天使'萨斯利尔。」（第六卷 阿蒙证实 L99057）
- 「'暗天使'萨斯利尔」始终是天国副君、神之左手、天使之王的首领（第六卷 多处 L L61936）
- 『我是这么回答的。他意味深长地再次问道：如果从目前所有的神灵里挑一位出来，往全知全能的主发展，你觉得谁最有可能？这……我心里闪过的第一个想法就是，能吞噬、放牧、驱使其他序列者灵魂和特性的'牧羊人'途径，而这条途径的尽头正是'真实造物主'。』
- 暗天使与诈骗犯萨斯利尔并立：「'暗天使'萨斯利尔的名号在大灾变后就消失了？」

**魔药配方**
- 主材料：**暗天使非凡特性或者萨斯利尔的影子或双手**
- 辅助材料：**原初上帝或远古太阳神的圣典一册，太阳、暴君、白塔、空想家领域天使的血肉50克（只需要其中两条途径的）**
- **仪式：飞向神秘学意义上的太阳，坚持一刻钟，以成为光明之影的一部分。**
- 魔药形态：时不时有光芒透出的纯黑液体。
- 非凡特性外观：长出了多根黑色羽毛的血色肉球
- 魔药口感：`【】`
- 扮演守则：`【】`

### 序列0 - 倒吊人

执掌堕落领域的真神，是黑色阴影与蠕动血肉的集合体。

> 序列0 级别的权柄和能力描述主要来源于及原著侧面描写的混合。

**非凡能力**
- "**阴影之主**"：阴影世界的主宰。
- "**暗**"：包容吞噬一切的黑暗和堕落人心的黑暗。
- "**堕落自性**"：每个生灵的堕落自性具现。
- "**污秽化身**"：自身被混沌海污染，也污染万物。
- "**异变**"：在黑暗中凭空制造怪物，具备复活特殊性。
- "**替罪**"：代替目标承受伤害和死亡。
- "**倒吊人**"：牺牲自我换取确凿的希望。

**原著佐证**
- 「极光会崇拜'真实造物主'，以倒吊的巨人作为那位存在的象征」
- 「那是不少神秘组织和隐秘教派共同信奉的一位古老存在，他们认为造物主并没有彻底死去，祂残留的核心就是真实造物主。自第五纪以来，真实造物主以多种形象出现过，比如'倒吊的巨人'，'阴影帷幕后的眼睛'」
- 「如果'真实造物主'能放牧另外二十一条超凡途径对应的神灵，从某种程度上来讲，祂就等于全知全能的造物主了。」

**魔药配方**
- 主材料：**"倒吊人"唯一性 + 三份"暗天使"特性**
- 辅助材料：**阴影世界**
- **仪式：于混沌海上行走，让影子溶入进去，而身体不沉，精神不坠。**
- 魔药形态：隔绝了周围所有光的黑暗影子。
- **唯一性外观：浓郁的影子**
- 魔药口感：`【】`
